# carousel-winners

Custom **carousel** block. Purpose: winner-stories.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1 = winner photo; cell 2 = heading (winner name), location paragraph, 'See all winners' link, game logo image, 'Winner' label, prize amount (optionally put logo, label and amount in a third cell).

| --- | --- |
| Autoplay | `autoplay` |
